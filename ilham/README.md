# ilham/ · Tasarım ilhamı

Güçlü hesaplardan beğenilen görseller. Haftalık gözden geçirmede 3-5 yeni örnek eklenir.
Dosya adı: `YYYY-MM-DD_hesap_kisa-konu.png` (ör. `2026-11-27_EpochAIResearch_benchmark.png`).
Her dosya için `ilham/index.csv` satırı: tarih, hesap, link, neden işe yarıyor, hangi şablona ilham.
Notion karşılığı: "Tasarım İlhamı" tablosu. Bu görseller sadece referanstır, birebir kopyalanmaz, yayınlanmaz.
